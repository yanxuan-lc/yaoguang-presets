# 研发运行目录

这是按需安装的目录模板，覆盖 macOS 和 Linux 上的 `~/.local/bin` 和 `~/.cache`。两条规则都读取**整个目录及其内容**，不是只读取已知工具或某个缓存子目录。具体条目见 [paths.json](paths.json)。

瑶光默认不安装此分类。这两个目录原属产品写死的默认可读范围，现在作为独立分类，由用户预览实际路径并确认后安装。安装分类只增加命令沙箱的读取范围，不安装研发工具，也不授予写入或网络访问。

`~/.local/bin` 可能含用户脚本、个人工具和脚本内的认证信息；`~/.cache` 可能含第三方应用缓存、私有包源码、日志和认证数据。目录被称为“缓存”并不保证其内容公开或不含秘密。只需要某个工具时，可优先安装相应技术分类或手动添加更窄的路径。

模板声明来自原产品默认范围，没有真实研发任务的沙箱运行验证。卸载分类只撤回它贡献的读取规则；若其他模板、手动路径或其他扩展仍提供同一路径，汇总中会保留该路径及其来源。
