# 基础运行环境

此分类声明 macOS 基础命令、动态库和系统运行数据的八个可读目录：

| 目录 | 读取范围 |
| --- | --- |
| `/usr` | 系统程序、库及其子目录 |
| `/bin` | 基础命令 |
| `/sbin` | 系统命令 |
| `/System` | 系统资源 |
| `/Library` | 系统及应用资源、配置 |
| `/private/etc` | 系统配置 |
| `/private/var/db` | 系统运行数据 |
| `/private/var/select` | 系统选择配置 |

每条规则均读取整个目录及其内容，具体声明与资料来源见 [paths.json](paths.json)。这是原产品八个写死系统目录的独立分类；不自动安装 Homebrew、Apple / Xcode、用户研发工具或账号分类。父目录内已有的工具或主机配置仍在递归范围内，例如 `/usr` 内的 `/usr/local`。

瑶光随产品携带本仓库真实 Git 提交的离线副本。平台首次遇到合法的 revision 0 空应用状态时，通过同一应用事务默认安装此分类并提交 revision 1，不需要联网。用户明确卸载后，重启或重新启用沙箱不会补装；已有非零应用修订也不自动追加分类。

安装只授予读取，不授予写入、网络或文件工具许可；密封状态根仍排除。`/Library`、系统配置和运行数据目录可能包含认证或私有主机数据，未标记认证风险的条目也不保证没有敏感内容。缺失目标不贡献权限，之后出现时也不自动获权。

远端同步只取得可用版本，不改变已安装版本。安装新版、卸载和重新安装均需核对路径预览并确认；随产品更新离线副本也不会自动更新已安装版本。平台的进程、设备及 literal 根路径基础规则由平台实现管理，不包含在此分类中。
